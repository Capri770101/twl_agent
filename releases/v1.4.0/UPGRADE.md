## 更新文件清单（规划）
- agent 业务身份校验、业务客户端、工具注册/路由、响应卡片、监控。
- H5 服务端可信身份桥接与业务查询授权；前端对话卡片和登录续办。
- 若新增数据表，提供独立有序迁移脚本、幂等验证和回滚限制。禁止直接改生产表来代替迁移文件。
- 提供 RELEASE_NOTES、配置示例（占位值）、自动/人工验收记录。
- 打包时列出实际新增/修改文件与 SHA256、对应提交；排除 .env、密钥、用户数据、开发缓存。

## 发布顺序
1. P0 核实实际部署基线；归档此前已部署但未提升版本号的增量。
2. 验证权限、旧功能回归和真实查询；备份数据库、代码、静态资源及旧镜像。
3. 如有迁移先在隔离库演练，采用向后兼容的增量迁移。
4. 部署 H5 身份/业务后端及 agent，新功能关闭；检查健康和接口授权。
5. 部署 H5 1.1.0；按测试账号灰度打开新能力。
6. 核对店铺、订单和售后真实数据，验证语音与多会话；记录实际结果后开放。

## 回滚
先关闭新能力，再回滚应用及静态入口；保留新增数据便于排查。不得在未知兼容性的情况下自动删除表或恢复整库，避免覆盖发布后的业务数据。迁移具体回退策略在 SQL 确定后补充。

## 发布阻断条件
可信用户映射未完成、越权测试失败、售后状态无法核实、缺少可用业务接口、关键回归失败：不得以模拟回复作为正式功能发布。
