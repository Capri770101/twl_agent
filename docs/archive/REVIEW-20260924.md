# 2026-09-24 智能体与 H5 联动审查

## 当前能力与边界

- 对话：流式文本、结构化卡片、会话记录与删除；工具产出作为方案和任务的事实依据。
- DIY：生成/修订方案、自动提交预览图、任务轮询；H5 登录后保存到账号，DIY 不直接结算。
- 贺卡：草稿、异步背景生图与文字合成；结算页编辑、账号保存约 90 天、每单最多五张并绑定商品。
- 语音：TTS/ASR、缓存、鉴权与限流；H5 录音/文件转写后编辑发送，播报开关持久化。
- 监控：语音调用次数、字符/秒数、缓存命中、失败与延迟。

## 本次确认并修复

1. 生图工具返回错误对象即便执行状态为 ok，也不能作为任务成功证据；以真实 task_id 判断是否需要补调。
2. 没有最终 respond_to_user 时，统一将真实 task_id/poll 合并到最终方案卡，避免任务已创建但客户端无法轮询。
3. latest_diy 明确读取最新 DIY，不用已选成品替代。
4. H5 普通 /chat 兜底响应保留 data 中的结构化卡片；避免 DIY 丢失结构后退化成可结算商品。
5. 任务 URL 归一化保持幂等，避免 /agent/agent/tasks；兼容布尔 poll，使用 task_id 构造路径。
6. H5 轮询时间与后端 300 秒陈旧任务界限对齐，429/5xx 可继续轮询。
7. ASR 限量读取上传；语音脚本在 ASR 失败时返回非零退出码。
8. 监控平均语音延迟按成功调用加权，避免展示调用较多的一方冒充全局平均。
9. H5 贺卡订单读写兼容 MySQL JSON 对象/字符串；服务端校验五张上限、正文和商品绑定。
