## 1. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Linux（生产为阿里云 ECS，华南 3·广州） |
| Docker | 24.x+，含 compose v2（`docker compose` 子命令） |
| 内存 | ≥ 2 GB（agent + postgres + nginx + dashboard） |
| 域名 | `api.tiaowulan.com`（已解析到 ECS 公网 IP `<REDACTED_HOST>`） |
| 端口 | 仅开放 80/443（阿里云安全组关闭 8000） |
| 外部依赖 | 阿里云百炼 DashScope 密钥；平台方只读 MySQL 连接串（可选） |

## 2. 部署架构（四服务）

| 服务 | 容器名 | profile | 暴露 | 说明 |
|---|---|---|---|---|
| `postgres` | `flora-postgres` | 默认 | 仅容器网络 | PostgreSQL 16，内部库 |
| `agent` | `flora-agent` | 默认 | `127.0.0.1:8000` | FastAPI 主服务（公网 8000 不开放） |
| `nginx` | `flora-nginx` | `nginx` | `80/443` | TLS 终止、SSE 反代、`/generated/` 静态 |
| `dashboard` | `flora-dashboard` | `nginx` | 容器网络 80 | 监控面板静态前端 |

> 公网收口：阿里云防火墙关 8000 + compose 绑 `127.0.0.1:8000:8000`；nginx 走内网 `http://agent:8000` 不受影响。重建后若 502 → `docker restart flora-nginx`。

## 3. 配置清单（`.env` 逐项）

复制 `.env.example` 为 `.env`，逐项填写。**生产必填项**：

```bash
# 服务
APP_ENV=prod
HOST=0.0.0.0
PORT=8000

# 数据库（生产必填 PostgreSQL，禁止 SQLite）
DATABASE_URL=postgresql://flora:<POSTGRES_PASSWORD>@postgres:5432/flora_agent
POSTGRES_PASSWORD=<openssl rand -base64 24 生成的强密码>

# LLM（阿里云百炼 DashScope，OpenAI 兼容）
LLM_API_KEY=<百炼 API Key>
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen3.8-flash
LLM_MAX_ITERATIONS=8
LLM_REQUEST_TIMEOUT=120

# 文生图（qwen 原生接口）
IMAGE_PROVIDER=qwen
IMAGE_API_KEY=<百炼 API Key>
IMAGE_MODEL=qwen-image-3.0
IMAGE_BASE_URL=https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
IMAGE_WIDTH=768
IMAGE_HEIGHT=1024
# IMAGE_PUBLIC_BASE_URL 留空则用 /generated 相对路径；生产建议指向 CDN/对象存储域名

# CORS（生产必须明确域名，禁止 *）
ALLOWED_ORIGINS=https://your-miniprogram.com,https://your-h5.com

# 鉴权（生产必填，JWT_SECRET ≥ 32 位）
JWT_SECRET=<openssl rand -hex 32>
JWT_EXPIRE_HOURS=720
AUTH_REQUIRED=true

# 多平台接入（platform_id=key，逗号分隔）
PLATFORM_API_KEYS=wxmini=<key1>,h5app=<key2>
# ANONYMOUS_LOGIN_ENABLED 生产默认关闭，勿显式开

# 监控面板密钥（未配置 /api/metrics 一律 503）
DASHBOARD_API_KEY=<openssl rand -hex 32>

# 微信登录（可选，启用 /auth/wx-login 时填）
WECHAT_APPID=
WECHAT_SECRET=
```

**腾讯 hy fallback（可选）**：保留 `HY_API_KEY` 时，百炼异常会按 provider 链回落 hy。跨厂商兜底可能导致回答风格跳变（曾致「答非所问」）。如需纯 Qwen，清空 `HY_API_KEY`。

## 4. 容器化部署步骤

### 4.1 首次部署

```bash
cd /opt/flora_agent_package
git clone <repo> .            # 或 git fetch && git merge --ff-only origin/main
cp .env.example .env && vi .env   # 填好上面必填项
docker compose --profile nginx up -d --build
docker compose ps             # 确认 4 容器 healthy
curl -k https://localhost/health   # 应返回 ok
```

### 4.2 代码更新（改了代码必须 --build）

```bash
git fetch && git merge --ff-only origin/main
docker compose --profile nginx up -d --build agent dashboard nginx
docker exec flora-nginx nginx -t && docker exec flora-nginx nginx -s reload
```

> 关键：**代码靠 `Dockerfile COPY . .` 烤进镜像**，改代码只 `restart` 无效，必须 `--build agent`。`.dockerignore` 必须排除 `deploy/letsencrypt`（root 700 权限会 build 失败）+ `.git/__pycache__/*.pyc/*.db/data`。

### 4.3 仅前端/配置变更（无需重建 agent）

- 改 dashboard 静态文件：`docker compose --profile nginx up -d --build dashboard`（注意它会连带重启 agent，等约 30s 健康检查恢复）。
- 改 nginx.conf（bind mount）：`docker exec flora-nginx nginx -s reload` 即生效，不必重建。

## 5. nginx / TLS 配置

- 证书放 `deploy/certs/{fullchain,privkey}.pem`（compose 挂载 `/etc/nginx/certs`）。
- 来源：阿里云免费证书（控制台下载 Nginx 格式，3 个月有效期，到期覆盖后 `docker restart flora-nginx`）。Let's Encrypt 仅备用（本机 acme-v02 出站被墙）。
- 三个关键 location（`deploy/nginx.conf`）：
  - `location /` → `agent:8000`，`proxy_buffering off`（SSE 可用），`proxy_read_timeout 300s`。
  - `location /generated/` → `agent:8000/generated/`，30d 强缓存。
  - `location = /dashboard` 302 → `/dashboard/`；`location /dashboard/` → `dashboard:80`（API/SSE 仍走 `location /` 反代回 agent）。
- Dockerfile 国内源：必须 sed 换阿里云源（改 `sources.list` 和 `debian.sources`），装 `fonts-wqy-microhei`（5MB）而非 `fonts-noto-cjk`（300MB+），否则国内 build 卡死。

## 6. 监控面板部署

- 已包含在 `docker-compose` 的 `dashboard` 服务（profile `nginx`），随 `--profile nginx` 自动起。
- 访问 `https://api.tiaowulan.com/dashboard/`，输入 `DASHBOARD_API_KEY` 登录。密钥只存 `sessionStorage`，不落盘、不进前端源码。
- `DASHBOARD_API_KEY` 太短或外泄会让面板裸奔；建议 `openssl rand -hex 32` 生成。改值后 `docker compose restart agent`（无需重建）。
- 若需换高强度密钥：`vi .env` 改 `DASHBOARD_API_KEY` → `docker compose restart agent`。

## 7. 升级 / 回滚

| 场景 | 操作 |
|---|---|
| 正常升级 | `git merge --ff-only` → `up -d --build agent dashboard nginx` → `nginx -s reload` |
| 回滚到上一版本 | `git checkout <旧commit>` → 同上 `--build` 重建 |
| 仅配置回滚 | 改 `.env` → `docker compose restart agent` |
| 镜像损坏 | `docker compose build --no-cache agent` 全量重 build |

> 版本基线：2026-09-04 三端一致于 `aa91d1c`；当前 `1a72ab6`（含调用监控面板 + LLM 切换百炼）。详见 [docs/11-变更记录.md](./11-变更记录.md)。

## 8. 常见坑（必读）

1. **改代码没生效**：忘记 `--build agent`，只 restart 了。
2. **502 网关错误**：重建 agent 后 nginx 未感知，执行 `docker restart flora-nginx`。
3. **生图 404**：qwen-image 不走 OpenAI 兼容 `/images/generations`，必须走原生 `multimodal-generation`；尺寸格式是 `"768*1024"`（星号）。
4. **监控 503**：`DASHBOARD_API_KEY` 未配置 → `/api/metrics` 一律 503。
5. **SSE 实时流 401**：dashboard 的 `EventSource` 不能自定义 header，必须走 `?key=`，后端须同时支持 header 与 query 校验（见运维手册第 7 节 K-2）。
6. **GitHub 推送失败**：沙箱网络波动可能 `Failed to connect to github.com port 443`。兜底 scp 直传 + 服务器重建（详见运维手册第 4 节）。
7. **容器内排障**：`docker exec -e PYTHONPATH=/app flora-agent python /tmp/x.py`。
