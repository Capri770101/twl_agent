# v1.2.0 发布记录（候选）

## 范围

本版本只做可回退的意图路由和工具范围实验，不改变生产默认行为：

```dotenv
AGENT_INTENT_ROUTING_ENABLED=false
CARE_TOOL_SCOPE_ENABLED=false
```

演示验证使用两个开关均为 `true`。

## 验收

必须验证：

1. 独立养护问题不调用商品、DIY、生图工具。
2. 生图请求无真实 DIY 方案时直接拒绝，不重复推荐。
3. 贺卡问题不触发商品或 DIY 工具。
4. 混合需求不被过度分类，继续使用完整 ReAct。
5. token、耗时、工具序列和最终回答均记录。

## 回退

关闭两个 feature flag 并重启对应 agent 容器即可回到 v1.1.0 的路由行为；镜像和数据库不变。
