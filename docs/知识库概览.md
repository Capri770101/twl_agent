# 花艺知识库概览（源码候选）

本页按当前 `agent/knowledge/store.py` 的可检索域和仓库 JSON 文件更新；它描述**本地知识检索**，不是实时商品、店铺或交易能力。数据条目数为本次源码快照的 JSON 顶层列表长度，以实际仓库文件为准。

| 检索域 | 数据文件 | 条目数 | 边界 |
|---|---|---:|---|
| `flower` | `flowers.json` | 78 | 花材资料，不代表平台实时库存或价格 |
| `style` | `styles.json` | 12 | 花艺风格 |
| `scene` | `scenes.json` | 32 | 使用场景 |
| `pairing` | `pairings.json` | 40 | 搭配规则 |
| `budget` | `budget.json` | 6 | 建议预算档位，不是商家的报价 |
| `packaging` | `packaging.json` | 7 | 包装方式 |
| `care` | `care.json` | 30 | 鲜切花养护知识 |
| `colors` | `colors.json` | 41 | 颜色名称和色值，可通过 `retrieve_knowledge(domain="colors", query="香槟")` 查询 |
| `proven` | PostgreSQL `diy_plans` | 动态 | 已确认/成交的本地方案检索；依赖数据库，不是实时交易数据 |

静态域合计 **246 条**，`proven` 不计入其中。`all` 查询覆盖上述域，动态方案仅在数据库有可用记录时返回。`shop` **不是知识检索域**，不应对模型或接入方宣称存在商家智库。经明确授权的平台店铺查询是另外的实时只读工具；没有平台数据源或授权时不得编造商家信息。

## 检索方式和更新边界

`query_knowledge(domain, query)` 的空查询列举该域；短查询以关键词命中为主，较长查询可结合字符 unigram/bigram TF-IDF 相似度。实际阈值及开关取 `backend/config.py` 的运行配置；可选 embedding 通道默认关闭，失败时回退到 TF-IDF。静态 JSON 有进程内缓存，更改文件后需重新启动服务；`proven` 每次查询读取数据库，索引和 embedding 使用同一批记录快照以免评分错位。检索相关度不等于事实真实性，不得据此承诺实时价格、库存、配送、下单或商家联系。

`knowledge_manifest.json` 列出的外部数据集仅是候选来源，不代表已导入；实际使用前须核验来源许可、质量和字段映射。知识检索契约回归参见 `tests/test_knowledge_domains_contract.py` 与 `tests/test_proven_index_snapshot.py`。
