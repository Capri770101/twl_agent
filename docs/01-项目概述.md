## 1. 项目定位与价值

本项目是一套**花艺领域 AI 智能体（ReAct 架构）后端服务**。它把「花卉知识、花束方案设计、AI 生图、电子贺卡、店铺/商品查询」等能力，封装成一套**平台无关的 HTTP API**，供微信小程序、H5、App 等前端以最小改造成本接入。

核心价值：

- **能力即服务**：前端只需「拿 token → 调 /chat」，无需自建模型、知识库、生图管线。
- **多平台隔离**：一套后端服务多端（小程序/H5/App）接入，平台密钥与用户身份由宿主自己掌握。
- **只读安全**：商品/店铺/订单数据实时只读查平台库，智能体不镜像、不落订单、不直接下单。
- **可观测**：内置调用监控面板，覆盖调用量、平台分布、工具调用、延迟、错误率与实时流。

## 2. 目标用户与场景

| 角色 | 场景 | 接入方式 |
|---|---|---|
| C 端用户（买花人） | 问花、挑花束、DIY 定制、看效果图、收电子贺卡 | 微信小程序 / H5 |
| 花店商家 | 用户从某店铺进入时锁定店铺，推荐与查询均限定本店 | 平台 `shop_id` 注入 |
| 平台运营 / 研发 | 看智能体调用量、延迟、错误、工具分布，定位异常 | 监控面板 |
| 接入方后端 | 用平台密钥为用户换 JWT，再把请求转发到智能体 | `POST /auth/token` |

## 3. 产品形态

- **纯后端服务**：不含小程序前端。前端通过 HTTPS 调 HTTP API。
- **独立部署**：阿里云 ECS（广州），域名 `api.tiaowulan.com`，TLS 在 nginx 终止。
- **多平台接入**：接入方后端持有 `PLATFORM_API_KEYS` 为自己的用户换取智能体 JWT；智能体只认 JWT 的 `sub`，不接触平台密钥。
- **不直接下单**：智能体输出结构化商品推荐（reply + products），用户在**小程序现有结算页**完成下单（见 `docs/03-系统架构设计.md` 第 4 节「勿回退架构决策」）。

## 4. 能力地图

| 能力 | 说明 | 关键工具 / 接口 |
|---|---|---|
| 自然语言对话 | ReAct 多轮对话，支持意图识别（buying/qa/chitchat/design/other） | `POST /chat` |
| 花艺知识问答 | 检索花卉知识库（花语/色系/季节/价格/搭配） | `retrieve_knowledge` |
| DIY 方案设计 | 结构化花艺方案（主花/配材/配比/色彩/包装/寓意/预算） | `generate_diy_plan` / `revise_diy_plan` |
| AI 生图 | 依据方案生成效果图（qwen-image-3.0，原生接口） | `generate_effect_image` + `GET /tasks/{id}` |
| 电子贺卡 | PIL 模板合成 5 套风格贺卡，落盘 PNG | `suggest_greetings` / `render_greeting_card` |
| 店铺/商品查询 | 只读查平台库标准实体 plan/shop/order/user | `platform_db_query_entity` |
| 用户画像与记忆 | 长期偏好（送花对象/风格/色系/预算） | `get/save_user_profile` / `save_memory` |
| 监控可观测 | 调用量/平台/工具/延迟/错误 + 实时流 | `GET /api/metrics/*` + SSE |

## 5. 技术栈总览

| 层 | 选型 |
|---|---|
| 语言 / 运行时 | Python 3.12（生产容器）/ 3.13（本地托管） |
| Web 框架 | FastAPI + Pydantic v2 |
| 智能体 | 自研 ReAct（`agent/`），工具注册表 `TOOL_REGISTRY` |
| LLM | 阿里云百炼 DashScope，`qwen3.8-flash`（OpenAI 兼容 `compatible-mode/v1`）；hy 作为 fallback |
| 文生图 | 阿里云百炼 `qwen-image-3.0`（原生 `multimodal-generation`） |
| 数据库 | PostgreSQL 16（内部库：会话/消息/记忆/DIY/生图任务/监控日志） |
| 平台外部库 | MySQL（只读，`flower_shop`，`SET SESSION TRANSACTION READ ONLY`） |
| 部署 | Docker + docker-compose（4 服务），nginx 反代 + TLS |
| 监控 | 独立 dashboard 静态前端（nginx:alpine）+ 后端 `observability.py` / `routers/metrics.py` |

## 7. 术语表

| 术语 | 含义 |
|---|---|
| 智能体 / Agent | 本项目的 ReAct 对话后端服务 |
| ReAct | Reasoning + Acting，模型先推理再调用工具的多轮范式 |
| 宿主 / 平台 | 接入本项目的前端及其后端（如微信小程序运营方） |
| `shop_id` 锁定 | 用户从某店铺进入时，会话四层贯通锁定该商家 |
| 平台外部库 | 商品/店铺/订单所在的第三方 MySQL，本项目只读 |
| `TOOL_REGISTRY` | 运行时工具注册表，决定 LLM 可用的能力集合 |
| 监控面板 | `https://api.tiaowulan.com/dashboard/`，独立于业务的前端 |
